# SOLUTION

## 1. Solution Ideation: Crazy 8s Exercise

### Problem:

Users find it difficult to book hospital appointments quickly and efficiently using existing healthcare apps.

### Crazy 8s Ideation (8 Ideas in 8 Minutes)

1. **Smart Auto-Scheduling**
   Automatically suggests the best available doctor and appointment slot based on user availability.

2. **Voice-Based Appointment Booking**
   Users can speak commands to book appointments quickly.

3. **Emergency Quick Booking**
   One-tap emergency consultation booking for urgent medical needs.

4. **Symptom-Based Doctor Suggestion**
   Suggests specialists based on symptoms entered by users.

5. **Family Profile Management**
   Allows users to manage appointments for family members from one account.

6. **Doctor Availability Radar**
   Displays nearby doctors and available slots visually.

7. **Live Chat Assistance**
   AI or support chat helps users during booking.

8. **Quick Re-Booking Feature**
   Enables users to rebook previous appointments instantly.

These are low-fidelity solution ideas generated during the ideation process.


# 2. Creating User Stories

### Persona Example

* **Name:** Priya
* **Age:** 32
* **Occupation:** Marketing Manager
* **Goal:** Book appointments quickly during work breaks.

### User Stories

1. As a working professional, I want to book appointments quickly, so that I can save time during my busy schedule.

2. As a parent, I want to manage appointments for my family members, so that I can track everyone’s healthcare in one app.

3. As a first-time user, I want symptom-based doctor suggestions, so that I can choose the correct specialist confidently.

4. As a busy user, I want to view all available doctor slots easily, so that I can select a convenient appointment time.

5. As a returning patient, I want to rebook previous appointments quickly, so that I can avoid repeating the booking process.



# 3. Creating Scenarios

### Selected User Story

*As a working professional, I want to book appointments quickly, so that I can save time during my busy schedule.*

### Scenario

Priya is a 32-year-old marketing manager working in a busy office environment. During a short coffee break, she remembers that she needs to consult a dermatologist for a skin allergy. She opens the hospital appointment app on her phone while sitting in a noisy break room.

She feels slightly stressed because she only has a few minutes before returning to work. Priya wants a fast and simple booking experience without navigating through multiple screens.

The app quickly loads, asks her symptoms, and suggests nearby dermatologists with available slots. Priya selects a Saturday morning appointment and confirms it within one minute. She feels relieved and satisfied because the booking process was smooth and efficient.
